# Plans — Index

Implementation plans per feature.

Plans are **mandatory before implementation** (see [AGENTS.md](../../AGENTS.md))
and are **historical / non-authoritative** once the work is done; they never
define current behavior.

New plans go in `documents/plans/<feature>/plan.md`.

Historical plans (from the former `documents/plans/`) are archived under
[../legacy/](../legacy/README.md) — they are reference-only.
